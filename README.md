# Blentinkerkit
Blentinkerkit è un insieme di applicazioni scritte in Python e in C++ che consentono di pilotare il braccio robotico Arduino TinkerKit attraverso il software di animazione gratuito Blender. L’obiettivo è quello di far prendere al braccio una spugnetta per disporla in un punto voluto in modo automatico. Tutto ciò è reso possibile grazie all’ADD-ON blendixserial di Blender che consente di interfacciare Blender mediante una porta USB del PC con la scheda Arduino1 che pilota il braccio. Attraverso una videocamera collegata al PC che inquadra l’area in cui è collocata la spugnetta, il software in Blender fotografa la scena e dall’analisi della fotografia crea i comandi di animazione del braccio per prenderla e depositarla nel punto voluto.
